# Experiment Scripts

Ad-hoc experiment runners used for paper or large-scale runs.

## Files

- `run_usenix_exp.sh`: run one config with optional tmux worker pane
- `run_usenix_bugfix.sh`: USENIX bug-fix flow helper
- `run_test_inc_build_wireshark.sh`: targeted incremental-build test

Prefer `crsbench run/worker/evaluator` directly for day-to-day usage.
